# Rust API

The Rust API reference is generated with `cargo doc --workspace --no-deps` and
published inside this documentation site after the TypeScript/WASM TypeDoc site
is generated.

<ul>
  <li><a href="../rust/peerbadge_protocol/index.html">Protocol crate</a></li>
  <li><a href="../rust/peerbadge_wasm/index.html">WASM crate</a></li>
</ul>

Use the TypeScript/WASM API reference for browser and npm integrations. Use the
Rust API reference when working directly with the protocol crate or checking the
implementation-level documentation behind the WASM surface.
